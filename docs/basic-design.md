# Agentraco Basic Landing Page Design

Status: Draft v1  
Last updated: [today's date]

## Page goal
Create one simple, clear trust page for restaurants.

## Design direction
- clean
- simple
- calm
- professional
- not flashy
- easy to read

## Page structure

1. Hero section
2. Problem section
3. Offer cards
4. How it works
5. Why Agentraco
6. CTA section
7. Footer

## Simple design rules
- lots of white space
- short text blocks
- one main accent color
- rounded cards
- clear buttons
- mobile-friendly layout

## Suggested style
- Background: white or very light gray
- Text: dark gray
- Accent: green or blue-green
- Buttons: simple solid button
- Font: default system font stack

## Hero layout
- left side: headline, subheadline, CTA buttons
- right side: simple placeholder card or visual panel

## Offer section layout
- 3 cards in one row on desktop
- stacked cards on mobile

## CTA section layout
- short heading
- one supporting sentence
- one main button
- contact email shown below
